# onova.tech

The Onova Tech website, served by GitHub Pages from `main` at https://onova.tech.

| Path | Purpose |
|---|---|
| `pocket-tools/privacy/` | Pocket Tools privacy policy (English); `pt-br/` and `es/` hold the translations. Keep all three in sync. |
| `app-ads.txt` | Authorizes Google AdMob to sell ads for our apps. AdMob reads it from the developer website listed in the Play Store. |
| `CNAME` | Custom domain for GitHub Pages. |
| `.nojekyll` | Serves the files as they are, without Jekyll. |

The pages load nothing from third parties (no fonts, scripts or analytics).
